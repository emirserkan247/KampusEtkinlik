# Kampüs Etkinlikleri — Sprint 1

Bu sprintte Kampüs Etkinlikleri projesinin temel yapısı yalnızca **HTML** kullanılarak oluşturuldu.

## Yapılanlar

- Semantik HTML yapısı oluşturuldu.
- Ana sayfa ve etkinlik sayfaları hazırlandı.
- Sayfalar arasında bağlantılar oluşturuldu.
- Etkinlik listeleme ve etkinlik detay sayfaları hazırlandı.
- Etkinlik ekleme ve güncelleme formları oluşturuldu.
- `header`, `nav`, `main`, `section`, `article` ve `footer` gibi semantik HTML etiketleri kullanıldı.
- Formlarda `label`, `input`, `select` ve `textarea` gibi HTML elemanları kullanıldı.

Bu sprintte CSS veya JavaScript kullanılmadan projenin temel HTML yapısına odaklanıldı.
